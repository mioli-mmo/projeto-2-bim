# Etapa 1 - SOAP e REST

## Objetivo

Integrar SOAP e REST com API Gateway, HATEOAS e cliente web.

## Backlog

- Documentar dominio e fluxo do projeto
- Criar APIs REST (eventos e check-ins)
- Criar API Gateway com HATEOAS
- Implementar servidor SOAP e expor WSDL
- Implementar cliente SOAP no Gateway
- Criar documentacao OpenAPI do Gateway
- Criar cliente web simples

## Testes manuais

- Consultar eventos via Gateway e conferir HATEOAS
- Criar check-in via Gateway
- Acessar WSDL do SOAP
- Chamar operacao SOAP via Gateway
- Validar cliente web consumindo Gateway
