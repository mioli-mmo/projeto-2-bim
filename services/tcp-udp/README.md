# TCP/UDP Service

Servidor TCP e UDP para simular leitores de QR.

## Portas

- UDP: 7001
- TCP: 7002

## Rodar

npm start

## Simuladores

- UDP: npm run client:udp
- TCP: npm run client:tcp

## Variaveis

- UDP_PORT, UDP_HOST
- TCP_PORT, TCP_HOST
- EVENT_ID, ATTENDEE
- GATEWAY_URL (default: http://localhost:4000)
